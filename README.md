# cryptography-games

密码学探索馆的开源游戏仓：**119 款可直玩游戏**，从凯撒、恩尼格玛到 AES、RSA、BB84 与后量子迁移。

## 直接试玩

GitHub Pages：<https://poyinet.github.io/cryptography-games/>

每款游戏位于 `games/<slug>/index.html`，全部使用相对路径，可直接在 GitHub Pages 项目页运行。

## 与三站的关系

- 正式游戏站：<https://play.poyi.net/>（由 `cryptography-site-play` 发布）
- 知识主站：<https://poyi.net/>
- 学习站：<https://learn.poyi.net/>

`games-manifest.json` 是游戏元数据与知识映射的唯一清单；正式站和 GitHub 直玩版都从同一份游戏源构建。
